UK Job Market Analysis | Python, Pandas & Data Visualisation

 About This Project

This project analyses a synthetic UK job-market dataset using Python to explore patterns in job demand, salaries, working arrangements and in-demand technical skills.

The aim was to use data analysis and visualisation techniques to identify trends that could support understanding of the UK technology job market.

  Analysis Performed

- Analysed job demand across different technology roles
- Compared median salaries across experience levels
- Examined salary differences across UK regions
- Analysed hybrid, remote and on-site working arrangements
- Identified the most frequently requested technical skills
  
 Tools & Technologies

- Python

- Pandas

- NumPy

- Matplotlib

- GitHub

 Key Findings

- The dataset contains 2,400 job listings.
- The median salary in the sample is approximately £48,984.
- Hybrid jobs make up around 56% of the sample.
- Salaries increase with experience level.
- Python, SQL and Power BI are among the most frequently mentioned skills.
